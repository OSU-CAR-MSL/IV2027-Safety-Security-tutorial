# IEEE IV 2027 tutorial website

This folder contains a complete, one-page static website for:

**Safety Meets Security: Toward Resilient and Trustworthy Autonomous Vehicles**

## Preview

Open `index.html` in a browser. No software installation, JavaScript framework, or website hosting is required for a local preview.

## Publish via GitHub Pages

1. Sign into GitHub and create a **public** repository, e.g. `iv2027-safe-secure-vehicles`.
2. Upload `index.html` at the **root** of the repository and commit it. (`README.md` is optional.)
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose **main** and **/(root)**, and click **Save**.
5. Once published, the URL will normally be `https://YOUR-USERNAME.github.io/iv2027-safe-secure-vehicles/`.
6. Open the URL in an incognito/private window to confirm public accessibility; paste that exact live URL into your IV proposal.
